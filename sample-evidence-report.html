What you are looking at

This is what a reviewer receives at the end of a job on Constellation: an evidence report. The AI proposes findings; this report shows, for each one, the exact passage of your policy and the exact log entries it relied on, whether plain code could find them, what was removed, and who signed off. It also ends with a fingerprint so anyone can re-check the result independently.

Read it in this order:

  • Section 1 (Summary): one finding proposed, one held for a person, one removed automatically.
  • Section 2 (Findings): for each one, the sources it cites and the checks run on it. A finding that fails a check is never presented as true.
  • Section 3 (Removed): a finding the record contradicts, kept visible so the removal can be audited.
  • Section 5 (What was not checked): the limits, stated plainly.
